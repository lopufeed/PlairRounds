# Шаблон веб-игры для PLAIR

Лёгкая стартовая игра на Vite и JavaScript без игрового движка. Сборка работает как статический сайт на GitHub Pages.

## Запуск

1. Установи Node.js LTS и Git.
2. В этой папке выполни `npm install`.
3. Выполни `npm run dev` и открой адрес, который покажет Vite. Для телефона и компьютера в одной Wi-Fi сети используй сетевой адрес из вывода терминала.
4. Перед публикацией выполни `npm run build`; готовая игра появится в `dist/`.

## Публикация на GitHub Pages

Создай GitHub-репозиторий, отправь в него файлы проекта и включи Pages: **Settings → Pages → Build and deployment → GitHub Actions**. Workflow `.github/workflows/deploy.yml` автоматически публикует содержимое `dist/` после отправки в `main`. В настройках репозитория можно проверить URL игры.

## Перед отправкой в PLAIR

- Добавь `cover.png` рядом с `index.html` (вертикальный 9:16) и, при наличии, `cover-square.jpg` (1080×1080 или больше).
- Скопируй выданный PLAIR код в `meta name="plair-verify"` в `<head>`.
- Не превышай 10 МБ суммарно; целись в 5 МБ и проверяй игру на телефоне по мобильной сети.
- Проверяй, что игру можно начать без аккаунта и установки, а все действия доступны касанием.
- Чтобы подключить очки, раскомментируй SDK в `index.html`; при окончании раунда пример вызывает `PLAIR.score(points)`, если SDK доступен.

## Где менять игру

- `src/main.js` — правила, состояние и ввод.
- `src/style.css` — оформление.
- `index.html` — название, описание, метаданные и подключение PLAIR.
- Изображения и звуки держи в `public/`, чтобы обращаться к ним по относительному пути `./имя-файла`.

Собранная игра должна работать на HTTPS и встраиваться в страницу. Не добавляй обязательные клавиатурные действия без альтернативы для касания.
