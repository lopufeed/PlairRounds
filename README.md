# PLΛNETS

Настольная космическая дуэль на одном поле. Перед забегом выбери один из восьми скинов планеты. Коснись своей половины, чтобы передвинуть планету. Проведи жест через центральную линию в поле соперника, чтобы запустить её. Перед каждым раундом — короткий стартовый титр, после попадания — цветной финальный титр.

Выбери игру против ИИ или локальное PvP. Поле автоматически становится широким на компьютере и остаётся портретным на телефоне. В каждой партии нужно выиграть два раунда, а для короны — пять партий. Попадание завершает раунд; броня и спутники могут перехватить планету.

## Запуск

Установи Node.js LTS, открой PowerShell в папке проекта и выполни `npm.cmd install`, затем `npm.cmd run dev`. Открой адрес из терминала. Чтобы выключить игру, нажми Ctrl+C в том же окне.

## Реликвии

В игре 30 карт, каждая улучшается до третьего уровня. После каждой партии оба бога выбирают реликвию: победитель улучшает найденную, проигравший получает новую. Реликвии меняют скорость движения и броска, броню, спутники и объекты на поле.

Светящиеся точки на своей половине дают заряд для бросков. Собирай их движением планеты. Осколки тоже появляются на арене: синие ускоряют следующий бросок, красные увеличивают планету, белые дают броню.

После партии оба набора улучшений показываются одновременно. Каждый игрок выбирает одну карту в своей половине экрана.

## Публикация

Сборка создаётся в `dist/` командой `npm.cmd run build`. Workflow в `.github/workflows/deploy.yml` публикует игру на GitHub Pages при отправке изменений в `main`.

Положи `cover.png` рядом с `index.html`. Для PLAIR добавь свой код в метатег `plair-verify`. Победа в кампании отправляет `PLAIR.score(5)`, если подключён SDK PLAIR.
